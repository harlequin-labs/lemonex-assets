# Lemonex assets

Public images for Lemonex, such as collection icons. Radix resource metadata (`icon_url`) must be a hosted `https://` URL, and the main Lemonex repo is private.

- `gnomes/icon.jpg`: The Gnome Society collection icon.
- `lemonex/icon.png`: the Lemonex dApp icon (512px). `lemonex/icon.svg` is its source.
- `lemonex/badge-icon.png`: the icon of the Lemonex owner and admin badges and the member NFT (512px, from the "Lx" app icon).
