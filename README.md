# Lemonex assets

Public images for Lemonex, such as collection icons. Radix resource metadata (`icon_url`) must be a hosted `https://` URL, and the main Lemonex repo is private.

- `gnomes/icon.jpg`: The Gnome Society collection icon.
- `lemonex/app-icon.png`: the Lemonex dApp and app icon (512px, trimmed from `lemonex/AppIcon.jpg`, which isn't pushed).
- `lemonex/badge-icon.png`: the icon of the Lemonex owner and admin badges and the member NFT (512px, the same as `app-icon.png`).
